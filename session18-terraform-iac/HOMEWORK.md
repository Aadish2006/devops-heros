# Homework: Terraform Infrastructure as Code

1. Define a small Terraform configuration using variables, outputs, and at least one resource supported by your provider.
2. Run `terraform fmt`, `terraform init`, and `terraform validate`, then review a plan before applying.
3. Inspect the state and explain why it must be protected and not committed when it contains sensitive information.
4. Destroy only the resources created for this exercise and verify cleanup.

**Deliverable:** Terraform configuration and sanitized command output. Do not include credentials or state files.
