# Homework: Docker Fundamentals

1. Build a container image for a small application using a Dockerfile.
2. Run the image with a published port and verify the application responds.
3. Inspect the container's logs and metadata, then stop and remove the container.
4. Explain the purpose of the Dockerfile, image, container, and port mapping in your workflow.

**Deliverable:** The Dockerfile, build/run commands, and verification output.
