# Homework: Docker Networking and Volumes

1. Run two containers on a user-defined Docker network and verify that one can resolve and reach the other by container/service name.
2. Mount a named volume into a container, write data, replace the container, and confirm the data remains.
3. Compare a named volume with a bind mount and describe a suitable use case for each.

**Deliverable:** Commands or Compose configuration plus evidence of service connectivity and persistent data.
