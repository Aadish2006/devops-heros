# Homework: Git and GitHub

1. Create a repository, make at least three meaningful commits, and inspect the commit history.
2. Create a feature branch, make a change, merge it into the main branch, and resolve a simple merge conflict.
3. Push the repository to GitHub and describe when you would use a branch and a pull request in a team workflow.

**Deliverable:** The repository link and a brief summary of the branch, merge, and conflict-resolution steps.
