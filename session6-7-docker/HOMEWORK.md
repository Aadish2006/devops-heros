# Homework: Docker Applications

1. Containerize a small web application and build its image.
2. Configure the application with an environment variable and persistent data where appropriate.
3. Use Docker Compose to run the application and its required services, then verify the app is reachable.
4. Rebuild after a code change and describe how image layers and Compose services fit together.

**Deliverable:** Dockerfile, Compose configuration, and a short run/verification guide.
