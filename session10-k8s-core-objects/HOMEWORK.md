# Homework: Kubernetes Core Objects

1. Create a Pod and a Deployment for a web container, then compare how each is managed.
2. Scale the Deployment, perform a rolling image update, and verify the rollout status.
3. Expose the Deployment with a Service and test access from inside the cluster.
4. Delete one managed Pod and explain how the desired replica count is restored.

**Deliverable:** Kubernetes manifests, verification commands, and a short explanation of Pods, Deployments, and Services.
