# Homework: Helm

1. Create or inspect a Helm chart for a simple web application and identify its templates, default values, and metadata.
2. Install the chart with a release name and at least one overridden value.
3. Upgrade the release, inspect its history, and roll back to the earlier revision.
4. Explain how Helm values and templates make an application reusable across environments.

**Deliverable:** Chart files or chart reference, install/upgrade commands, and verification output.
