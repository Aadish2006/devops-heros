# Homework: Observability and GitOps

1. Define a useful metric for a sample service and explain what a corresponding alert should detect.
2. Build a Grafana dashboard panel from a Prometheus metric and document what action an operator should take when it changes.
3. Store a Kubernetes application configuration in Git and deploy it through Argo CD.
4. Make a change in Git, observe reconciliation, then revert the change and verify the cluster returns to the declared state.

**Deliverable:** Dashboard evidence, Git-managed manifests, and a brief description of the reconciliation cycle.
