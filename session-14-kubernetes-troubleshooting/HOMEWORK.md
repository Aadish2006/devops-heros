# Homework: Kubernetes Troubleshooting

1. Diagnose a Pod that cannot be scheduled, one that repeatedly crashes, and one that cannot pull its image.
2. For each case, use `kubectl get`, `describe`, `logs`, and Events as appropriate to identify the cause.
3. Apply a minimal correction, verify recovery, and explain which observation led to the fix.
4. Investigate a Service connectivity failure by checking selectors, endpoints, ports, and DNS.

**Deliverable:** A troubleshooting report with symptoms, evidence, root cause, fix, and verification for each case.
