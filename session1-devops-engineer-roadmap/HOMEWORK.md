# Homework: DevOps Engineer Roadmap

1. Choose a sample application and draw a simple path from source code to production, naming the DevOps practices and tools used at each stage.
2. Identify three skills you already have and three you want to develop. Map each gap to a practical exercise or learning resource.
3. Write a short reflection on how automation, collaboration, and feedback improve software delivery.

**Deliverable:** A one-page roadmap with the workflow diagram and skill plan.
